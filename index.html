Three principles

Local-first

Every byte of your matter stays in a single .fdmatter folder on your Mac. Copy it. Archive it. Put it on iCloud. You control where the data lives. We never see it.

Defensible by design

Every state change writes to a SHA-256 hash-chained audit log with an NDJSON disk mirror. Tampering breaks the chain visibly. One click verifies the integrity of every action — including, especially, by us.

A complete loop

Ingest opposing's productions with cross-overlap detection. Build outbound productions with redaction burn-in and manifest hashes. Confidentiality designations travel from in to out.

What's in v1

Ingest

PDF, Office (modern + legacy), email (EML/MBOX/MSG/PST), images, audio, video metadata, plain text. SHA-256 and MD5 hashing. Content-addressed blob storage with automatic deduplication.

Review

Nine-tag palette with 1–9 hotkey coding. J/K navigation. Bulk operations. Family-aware grouping. Conversation rollup. Per-doc notes. Touched-today sidebar.

Redact

Reversible vector redactions until production. Then burned in via 200-DPI rasterization — the underlying text is removed, not just covered. Defensible.

Produce

Bates-stamped PDFs with redaction burn-in. Concordance .DAT + Opticon .OPT load files. JSON manifest with SHA-256 of every output file.

Receive

Concordance-style production import with column auto-mapping (200+ aliases). Five-strategy fuzzy file lookup. Auto-tag by volume name. Detect overlap with your own productions.

Compare

SHA-256 exact-duplicate detection across volumes. MinHash near-duplicate detection. Coding-consistency prompt when a near-dup of a privileged doc surfaces in another production.

Confidentiality

Designation tiers seeded with industry defaults (CONFIDENTIAL, AEO, HC-AEO, Trade Secret). Protective order / NDA wizard reads the order and proposes matching tiers via on-device LLM.

Predictive coding (TAR)

Multinomial Naive Bayes on your tags. Continuous Active Learning surfaces the most-uncertain documents. Concept search via Apple's NLEmbedding — fully local.

Detect

PII, PHI, privilege, and risk markers via NSDataDetector + regex. Risk-score aggregation per document. Sidebar filter for high-risk material.

Defensibility

Hash-chained audit log with NDJSON disk mirror. One-click integrity verification reports the first inconsistency. Every action timestamped and attributed to the reviewer.
